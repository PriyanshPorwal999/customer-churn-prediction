# Customer Churn Prediction

An end-to-end Machine Learning project designed to predict customer churn using customer behavior and service-related data. The project follows a modular and scalable architecture inspired by MLOps practices, including data ingestion, logging, exception handling, data transformation, model training, and prediction pipelines.

---

## Description

### Motivation

Customer retention is one of the most important challenges faced by businesses today. Acquiring a new customer often costs significantly more than retaining an existing one. By identifying customers who are likely to leave, companies can take proactive actions to improve customer satisfaction and reduce revenue loss.

### Why I Built This Project

I built this project to gain practical experience in developing production-ready machine learning systems rather than simply training a model inside a notebook. The focus was on learning how real-world ML projects are structured and maintained.

### Problem It Solves

The project predicts whether a customer is likely to churn based on historical customer information. Businesses can use these predictions to identify at-risk customers and implement retention strategies.

### What I Learned

* Building modular machine learning pipelines
* Data ingestion and artifact management
* Exception handling and logging
* Data preprocessing and feature engineering
* Model training and evaluation
* Writing production-quality Python code
* Git and GitHub workflow
* Project structuring for scalability

## Installation

### Clone the Repository

```bash
git clone https://github.com/PriyanshPorwal999/customer-churn-prediction.git
cd customer-churn-prediction
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
